# Security Policy

## Reporting a vulnerability

Please do not publish credentials, private PGNs, personal data, or exploit details in a public issue.

Until a private security contact is published for this project, use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, contact the repository owner privately through an established channel.

Include the affected version or commit, impact, reproducible steps, and any relevant sanitized logs. Do not include secrets or another person's private game data.

## Supported versions

Security support and release support windows have not yet been formally defined. Use the latest maintained commit and verify its status before deploying it for public use.
